Living Style Guide

The aiio system, rendered on its own tokens.

A Microsoft Fluent 2 language, re-skinned: a Zinc neutral ramp, a single purple brand accent, an Untitled-UI status palette, and a two-font pairing — Chillax titles over Segoe UI body. Every value below reads from the same CSS variables you ship — verified against Figma. Toggle the theme to see both resolve.
